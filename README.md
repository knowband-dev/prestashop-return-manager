# PrestaShop Free Return Manager for PrestaShop 1.7x, 8.x and 9.x

PrestaShop Free Return Manager by Knowband gives store owners a structured way to handle product return requests instead of managing them manually over email. This module is compatible with the EU Withdrawal Rights Directive, allowing merchants to streamline return request management while offering customers a simple and transparent return process.

With this module, registered customers can raise a return request from their account or order page. The admin reviews the request, approves or rejects it, and the customer is automatically notified by email at each stage. This module is compatible with the default PrestaShop theme.

Module product page: [PrestaShop Return Manager](https://www.knowband.com/prestashop-return-manager)

## Features

Key features of the PrestaShop Free Return Manager Module:

- Return requests for both registered and guest customers
- Admin approval workflow with automatic email notifications
- Configurable return policies for the store
- Up to three predefined return reasons customers can choose from when submitting a request
- Centralised management of all return requests from the back office

## Installation

1. Navigate to **Module Manager**, click **Upload a module**, and upload the module's ZIP file. Once installation is complete, click **Configure**.
2. You'll be redirected to the module's **General Settings** page, where you can begin configuring the module.
3. Set up your return policy, reasons, and notification settings from the module configuration page.
